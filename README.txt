AeroBagTrack - Airport Baggage Tracking and Recovery Management System

Open the AeroBagTrack folder in IntelliJ IDEA.
Source files are in src/.
Main class: Main.java (default package).

Requirements:
- JDK 17 or later recommended.
- The console application works in memory without MySQL.
- Optional JDBC setup is provided in util/DatabaseConnection.java.
- To use MySQL, create database with:
  CREATE DATABASE aerobagtrack;
- Add MySQL Connector/J to IntelliJ dependencies before using JDBC classes.
- Change the database password in DatabaseConnection.java.

This is a clean, self-contained starter project. It does not contain your
personal local IntelliJ settings or your previous files.
